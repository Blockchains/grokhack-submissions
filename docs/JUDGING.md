# What judges look at

1. **Grok at the core**: the product would not work without Grok (models, tool calling, live search, structured output, vision, voice).
2. **Working demo**: a live URL or a video of the real thing. Fake data or mocked API responses are disqualifying.
3. **Partner platform depth**: real integration with the platform you chose (grokhack.com/platforms).
4. **Craft**: code quality, CI green, README a stranger can follow, no committed secrets.
5. **Impact**: who it helps and how much.

Submit by setting `"status": "submitted"` in `submission.json` (CI then requires reachable `demo_url` and `video_url`) and opening the entry issue on grokhack.com.
